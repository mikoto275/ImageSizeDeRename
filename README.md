# 画像サイズdeリネーム

画像ファイルの縦横サイズを取得し、
ファイル名へ一括付与するWindows向けGUIツールです。

## 主な機能

- 画像サイズ（幅×高さ）を取得してリネーム
- 接頭辞・接尾辞に対応
- 区切り文字（_ / - / なし）選択可能
- リネーム前プレビュー
- 元に戻す機能
- 既に画像サイズが付与されているファイルを自動検出

## 使用例

変更前

sample.jpg

変更後

3840x2160_sample.jpg

## 動作環境

- Windows 10 / 11

## 使い方

1. フォルダを選択
2. プレビューを確認
3. リネーム開始をクリック
